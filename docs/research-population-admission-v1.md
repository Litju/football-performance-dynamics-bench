# Public SkillCorner research population admission, version 1.0.0

Status: PROPOSED FOR OWNER RATIFICATION AFTER FULL RECONCILIATION.

Contract identity: `fpdbench.public-skillcorner-research-admission/1.0.0`.
This separately governed local public-data research contract does not amend the
protected qualification contract, its trust policies, synthetic-only rejection,
blocked empirical API, frozen scientific authorities, or RES-339 execution gate.

The existing independently authored scientific verifier reconstructs source
canonicalization, origin enumeration, candidate rules, scene identities, fixed
origin panels, absolute and origin-relative targets, every future mask and
scoreability. Independent scientific derivation here means separately implemented
calculation in separate processes. It does not mean separate human custody,
externally authenticated machines or resistance to a malicious runtime/operator.

For this pinned public cohort, content identities and reproducible derivation are
the research acceptance criteria. External production signing infrastructure is
not required for this separate claim. No fictitious signer or production policy
is created. Content-addressed inputs are immutable by identity, not asserted to
be physically immutable; byte and mutation checks detect changes during this run.

## Scientific definition and acceptance

All 20 matches, exact 81-file inventory, pinned LFS/ordinary Git identities and
frozen 12/4/4 roles are mandatory. Source revision, v2 state/eligibility/protocol/
plan/schema hashes remain unchanged. Use canonical even frames from 10 Hz to 5 Hz,
25 history intervals + origin + 15 future intervals, 41 support slots, 39 finite
ball positions and finite origin, frozen player/appearance/coordinate rules,
fixed finite-origin panels, both target representations and final-slot scoreability.
Primary normalization is C `fpdbench.skillcorner.phase-period-intersection/1.0.0`;
missing phase coverage is unknown, not dead ball. B remains sensitivity only.

`tools/research_population_v1.py run SOURCE FRESH_PRIVATE_OUTPUT CENSUS_JSON`
checks storage/memory estimates, original source identities and a full code/runtime
inventory, stages private inputs with C lineage, and launches separate bounded
producer and independent verifier processes. Both assess every theoretical origin,
including incomplete support. Separate per-match streams permit bounded parallel
execution. No protected-production execution API is called or monkeypatched.
Existing producer calculation helpers are reused; historical worker receipts are
neither produced under false labels nor reclassified.

The independent verifier uses the existing standalone scientific implementation,
not producer/canonicalizer/eligibility imports. It independently checks original
source identities and rederives C bytes and ordered phase lineage from raw CSV and
metadata. The research wrapper records current code inventories rather than
weakening the historical verifier's PR-specific package pin. Exact canonical row
bytes and SHA-256 must match for every match. Each row binds role, period, exact
origin/frame, complete support, full diagnostic including exclusions/warnings,
window identity and full directed-scene truth/panels/masks/scoreability. All source
and output identities and per-period/match/role totals must agree. Prior census
counts inform resource estimates and are reported as comparisons, never oracles.

Private row streams are the versioned research wire format described above.
They are not the protected population authority schema and cannot satisfy its
signing/authentication gate. Only aggregate, non-reconstructive reports may leave
private storage. Keep exact code commit, full package/tool inventories, Python
executable digest, dependency versions, source/normalization identities and both
reconstructions for reproduction. Require a fresh output root; interrupted runs
retain partial evidence and never emit a successful admission manifest.

Successful scientific reconciliation emits `RESEARCH_RECONCILED`, with admission
`RESEARCH_ADMISSION_PENDING_OWNER_APPROVAL`, protected status `NOT_QUALIFIED`, and
empirical execution blocked. Missing/mismatched inputs, drift, schema failure,
incomplete match set, changed code/source, unequal outputs or insufficient resources
emit `RESEARCH_RECONCILIATION_FAILED`, never a research pass. All 20 matches must
have scoreable windows; otherwise population completeness fails.
